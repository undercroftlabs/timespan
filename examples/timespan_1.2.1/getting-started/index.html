Inspect a duration

A timespan is the interval from a start instant to an end instant. Create one with new Timespan(start, end), then read its endpoints, calendar breakdown, and exact length. Fourteen days is two weeks in the calendar breakdown, while toMilliseconds() stays exact. isZero() is true when both endpoints are the same instant, and toString() is then an empty string.
