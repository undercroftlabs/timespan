Format a duration

This span starts at 2023-06-01T00:00:00.000Z and lasts 1,483,506,123 milliseconds. A format directive is %[flags][width][.precision]specifier. Uppercase specifiers are totals (%D is every day). Lowercase specifiers are the calendar components from toTimeframe() (%d is only the day remainder). %f is the fractional seconds, and %% is a literal percent. The instance and static format methods return the same text.

Flags are 0 to zero-pad, - to left-align, + to show a plus, and a space to leave a leading blank. Width is the minimum length. Precision is the minimum digits, except for %f, where it is the number of fractional digits.
