Build a duration from numbers

Named factories such as fromHours accept fractions of fixed-length units. fromUnits accepts the same amounts, including short names such as mins. fromObject takes a timeframe literal and applies every unit it contains. The start instant defaults to now when you omit it; these examples pass one so the end instant stays fixed.
