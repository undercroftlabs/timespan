@undercroft/timespan@1.3.0

Save and restore a timespan

toJSON returns { $type: "Timespan", start, end } with both instants as ISO strings. JSON.stringify calls it automatically. parse and fromJSON rebuild one timespan. JSON.parse(text, Timespan.reviver) rebuilds timespans nested in a larger document. isTimespanJSON checks that shape only: a true result can still fail when the strings are not a valid range.
